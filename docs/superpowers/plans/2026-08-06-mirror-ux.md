# Mirror UX Implementation Plan

> **For agentic workers:** Execute task-by-task. Steps use checkbox (`- [ ]`) syntax.

**Goal:** Add bidirectional clipboard, PiP, pinch-zoom gestures, volume-key mapping, and FPS/latency display to the scrcpy Android controller.

**Architecture:** Parse control inbound via `DeviceMessageReader`; sync clipboard with `ClipboardBridge`; extend `VideoDecoder` for stats; client-side transform via `MirrorGestureController`; wire PiP/volume/stats in `MirrorActivity`.

**Tech Stack:** Kotlin, Android SDK 26–34, coroutines, existing scrcpy 4.1 control protocol, dadb.

## Global Constraints

- No screenshot/recording/audio
- Clipboard auto-sync uses `paste=false` for host→device; keep existing IME paste path
- Pinch zoom is client-side only (1x–4x); multi-touch must not inject remote touches
- Verify with `./gradlew assembleDebug`
